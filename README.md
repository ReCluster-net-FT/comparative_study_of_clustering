# Comparative Evaluation of Cluster Head Selection Enhancements

### Overview

This project studies the use of GraphSAGE in cluster head selection algorithms for Wireless Sensor Networks (WSNs). It compares different methods to understand how graph information affects network lifetime and energy efficiency.

### Objectives

- Use GraphSAGE to learn information about sensor nodes and their neighbors.
- Integrate GraphSAGE while retaining the logic of the original algorithms.
- Compare the performance of each clustering algorithm before and after GraphSAGE integration.
- Study the impact of graph embeddings on network lifetime.

## Evaluation Metrics

- **FND (First Node Dies):** The round when the first sensor node dies.
- **HND (Half Nodes Die):** The round when half of the sensor nodes have died.
- **LND (Last Node Dies):** The round when the last sensor node dies.

These metrics help compare network lifetime across the different methods.
